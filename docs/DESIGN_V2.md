# 设计 v2（2026-10-17）

人确认要实现：推荐 logo、新版选型助手、实验台左上角面包屑、实验台 v2、全站移动端。
设计稿源文件在 `docs/design-v2/*.dc.html`（内联样式的静态 HTML，直接读源码取尺寸 / 颜色 / 文案；`support.js` 不在仓库里，不用打开渲染）。画布：https://claude.ai/artifact/X1Utcv8Wao1Ve3zk4oi5NZ （只有人能开）。本文件和 `docs/DESIGN.md` 冲突时以本文件为准。

## 0. 通用
- 色值沿用 DESIGN.md §2 的变量；新增 `--accent-strong #0B76C8` 用于 logo 底、主按钮。
- 不用 emoji，图标全部内联 SVG（stroke 2，round）。正文对比 ≥ 4.5:1。
- 触控目标 ≥ 44px（手机），桌面按钮 ≥ 32px。
- 断点：`< 768px` 用手机布局；`768–1023` 平板按桌面布局但面板可收起；`≥ 1024` 桌面。
- 设计稿里的价格、文案有占位，**以仓库真实数据为准**（catalog / works / templates），不要把设计稿的假数字写死。

## 1. Logo（Main.dc.html 标"推荐"的方案 1）
64 viewBox：`rect x4 y4 w56 h56 rx14 fill #0B76C8`；8 个白点 r=5（20/32 × 20/32/44 网格中除右上角 (44,20) 外）；右上角琥珀点 `#FFB020` r=6。
- 大尺寸（≥ 64px）右上点外加一圈 `r8.5 opacity .35` 光晕。
- 16px favicon 用简化版：只留 (20,20) (32,32) (20,44) (44,44) 四个白点 r=6 + 琥珀点 r=7。
- 暗色：底 `#3AA8FF`，点 `#17181B`，琥珀不变。
- 落地：一个共享 React 组件（`src/ui/` 下）+ `public/favicon.svg`（及 16px 简化版），所有 html 入口（home / levels / advisor / app / index / licenses）引用 favicon；页头统一用它，字标"试板"。

## 4. 实验台 v2（Workbench.dc.html；状态见 WorkbenchStates.dc.html）
只做真实存在的功能的界面；设计稿里有、但内核 / 数据里还没有的能力，做成灰掉的入口或不做，**不造假数据**。逐项：
- 顶栏：面包屑（§3）＋保存状态（"已存在本机 · 刚刚"，来自真实 session 存储）、撤销 / 重做（接现有 history / timeline，没有就做）、步骤条（组装 / 成品未解锁时带锁图标，title 写原因"实验台 N 个检查点全部通过后解锁"）、⌘K 入口、运行状态组（运行中 / 暂停 / 重启；倍速只在内核支持时出现）、"换固件"、⋯ 菜单（分享链接、导出输入日志、AI 任务书——都已有功能就接上）。
- 左栏：标签 构建树 / 元件库 / 接线表；构建树含"供电与环境"节点；零件按总线分组；有问题的零件带警告图标；当前检查点提示卡（"带我去接" 聚焦到相关引脚 / "看全部检查点"）。
- 台面：连线模式蓝色横幅（"连线中… Esc 取消"）、可连引脚高亮、引脚悬停提示（GPIO 名、占用 / 空闲、复用功能）、万用表常驻读数卡、视图按钮（顶 / 前 / 缩放 / 对准 F / 全屏）、底部工具条带快捷键字母、"?" 打开快捷键表。
- 右栏属性：可信度徽章、数据手册链接、标签 实时值 / 引脚 / 属性 / 可信度、60 s 曲线、滑块 + 数字输入、预设、"换成别的传感器" / "移除"。
- 底部坞：可拖高度、标签 串口 / 代码 / 逻辑分析仪 / 运行记录 / 检查点 x/y / 问题 n；过滤、时间戳、跟随最新、复制、清空、收起；日志按级别着色（E 红 / W 黄 / I 默认）；串口输入框 + 行尾选择。
- 关键状态（WorkbenchStates）：空台面引导、wasm 加载进度、拖入固件校验卡、连线中、接错线确认（撤销 / 改接 / 保留）、掉电复位解释、⌘K、检查点通过 toast、暗色模式。已有的状态改样式，没有的补上（只要有真实触发条件）。
- 不能回退的要求：现有 puppeteer 回归（tools/webtest/*.mjs）必须继续过；需要改选择器时同步改脚本，不削弱断言。

## 6. 统一实验台（2026-10-17；稿子 `docs/design-v2/unify/*.dc.html`，画布 https://claude.ai/artifact/WHknfihGH9ysHAEPBeJjHv）

### 6.1 一个实验台（Sitemap.dc.html）
- 示例 = 空白作品 + 示例的固件、台面、芯片：`app.html?work=blank&example=<id>#bench`。没有 `example` 就是真正的空白（台面只有开发板，等换固件）。

- 旧实验台独有的功能迁到工作台再删：示例说明卡 + 环境 / 模拟输入滑块 → 右栏属性（选中「这个示例」）；USB 虚拟电脑（键盘收到的字、CDC 终端）→ 底部坞「USB」页签（只在有原生 USB 示例时出现）；麦克风声源 → 右栏；声音开关 → 运行组；导出输入 → ⋯。

### 6.2 页头（Header.dc.html）
- 站点页头（首页 / 选型助手 / 授权）：logo + 试板 TRYBOARD；导航 **作品 / 选型助手 / 实验台**；右侧主题图标键。

- 运行组：状态点 + 运行中 | 倍速 | 暂停 / 继续 | 重启 | 声音。工具条、右栏不再各放「再跑一次」。
- 「换固件 ▾」（主按钮）打开菜单（Bench.dc.html）：C3 / S3 切换、该芯片的示例（当前打勾）、「上传自己的 .bin…」、最近用过（本机记录的上次上传文件名）。
- ⋯ 菜单：复制链接、导出输入日志、AI 任务书、授权与致谢；菜单底部一行商标声明。

### 8.1 可信度与结果状态（DesB）
两条轴不混：**可信度用填充、不用颜色**，**结果状态只用颜色**。
- 可信度图标 `web/src/ui/conf.tsx` 的 `ConfIcon`（16×16 viewBox，圆 r=6.2，描边 1.6，墨色 #1E1E1E）：
  - 仿真验证：实心圆
  - 行为模拟：描边圆 + 四分之三扇形 `M8 8V1.8A6.2 6.2 0 1 1 1.8 8Z`
  - 估算：描边圆 + 右半 `M8 1.8A6.2 6.2 0 0 1 8 14.2Z`
  - 必须上真机：虚线圈 `stroke-dasharray="2.4 2"`，不填充
- 图标后跟文字档名（不能只靠图形）；全站（选板、采购、实验台检查点、组装、成品）一律用它，旧的绿 / 蓝 / 黄 / 红可信度徽章退役。

## 9. 结果文案（2026-10-19；画布 https://claude.ai/artifact/JcgdpDMDhYyJfM92iAGm1y）
原则：**先说过没过，再说为什么**。第一层只写人话，工程数据（GPIO 号、占空比、ns、µA、地址）收进第二层「原始数据」。

### 9.1 六条
1. 结论先行：第一行回答「过了没有」；不过时第一行说哪里不对。
2. 主语是器件不是引脚：写「舵机」「蜂鸣器」，GPIO 编号放小字。
3. 说看得见的后果：「表盘多指了 2.5 ℃」比「脉宽 1.80 ms」好懂。
4. 一句话只说一件事：不套括号，不堆「·」「；」「✓✗」，句末不挂术语尾巴（可信度只用图标）。
5. 数字有对照：实际值旁边有目标值或常识值（室温、上限、建议值）。
6. 没过就给下一步：失败卡片配一个动词按钮；原始数据收在折叠里。

### 9.2 状态只用四个词
通过（#0E7A41 / #E8F7EE）· 没通过（#B42318 / #FEF2F2）· 没跑完（#444 / #F2F2F2）· 装壳后变了（#8A5A12 / #FDF4E3）。界面上不再出现「未通过 / 未过 / ✓ 通过 / ✗ 未通过 / 复测 ✗」。命令行（check.py、npm 包）输出不变。

### 9.3 用词表
| 现在 | 改成 |
|---|---|
| ✗ 未过 / 未通过 | 没通过 |
| （要 ≥ 300） | 至少 300 |
| I2C 0x76 应答 0 次 | BME280 没有回应（0x76 放小字） |
| GPIO5 翻转 7 次 | LED 闪了 7 次 |
| 响 0 声（要 2–5） | 蜂鸣器没响 |
| 占空比 0.090 | 收进原始数据 |
| 欠压复位 | 电压不够，芯片重启了（术语放小字） |
| 在规范内 | 没问题 |
| 指纹 / 运行指纹 | 运行编号（悬停：网页和命令行编号一致 = 结果可复现） |
| 清单没问题 · 32 条规则通过 | 清单齐了，可以照着买 · 共检查 32 项 |

### 9.4 落点（PLAN U-20）
检查点结果（实验台属性面板 + 手机）、组装开机复测、没跑完、欠压提示、采购清单检查、线束估算、真买卡、选板「为什么是它」。实现：`web/src/ui/say.ts`（状态词、器件名、标题汇总）；`checks.ts` 的 `CheckResult` 加 `say`（人话）和 `tag`（小字），`text` 保持与 check.py 逐字一致，作为原始数据。

### 9.5 结果卡 v2 精修（2026-10-19；画布 https://claude.ai/artifact/PT6QqqxSYZdiaiLarXo4K1，PLAN U-21）
1. **四种状态 + 跑中**：跑中卡（进度条 + 「模拟中」）、通过、没通过、没跑完、装壳后变了，全用同一张结果卡。状态词胶囊 24 高、带 12 px 图标。
2. **一张卡只有一个主动作**：没通过 → 「复制给 AI 修」（任务书 + 没过的几条），次要「用参考固件对比」；自己的固件通过 → 「下一个检查点」；没跑完 → 「再跑一次」；装壳后变了 → 「重装<零件>」（退回到装那一件之前），次要「再复测」。
3. **原因只写一次**：组装复测有结果后，卡上方的提示句不再显示；装壳后变了的原因 = 出问题那件零件的提示 + 「改成「正确位置」再测。」。
4. **逐条按器件分组**：组头写器件名 + 引脚 / 地址小标签（等宽），只写一次；同一器件两条以上没过时合成一句（「蜂鸣器一直没响」/「蜂鸣器有 N 处不对」），细节缩成小字；组里通过的收成「其余 N 项正常」。时间窗、数值留在原始数据。标题按器件数：「有 N 个器件不对」。
5. **图标**：16 px SVG（勾 / 叉 / 三角 / 点），行最小 36 高、垂直居中；装壳后变了的行用琥珀三角，不用红叉。
6. **原始数据**：整行按钮（44 高、自绘箭头），写明「N 条结论 + 运行编号」；里面仍是与命令行逐字一致的结论行。
7. **手机**：工具栏编辑类按钮一行（最多 4 列），主按钮（开机复测）单独整行 48 高，不再孤零零掉到第二行。底栏主按钮随结果换：复测没通过 → 「重装<零件>」，其余 → 「下一步：成品」。
8. **真买卡**：48% 黑遮罩 + 阴影，`role=dialog`，点遮罩 / Esc / 右上 ✕ 关；三栏等高、按钮钉在底；清单只露 3 件 +「还有 N 件」，不套滚动、不截断；大数字正文黑 28 号等宽数字（蓝色只给能点的）；实线描边。成品页里内嵌的那份不加遮罩。
9. **选板「为什么是它」**：左列只放数字 + 单位（28 号、右对齐、等宽数字）；「✓ / ! / ✗ / USB / ¥」改成小标签；差价不带「+」号；续航总数只在答案卡出现，理由里说比最便宜的多几天；每行可信度图标旁带字，图例常驻卡下。
10. **字号五档**：28/36 · 20/28（结果标题，手机 17）· 15/24 · 13/20 · 12/16；间距只用 4 的倍数。`--muted` 亮色 #6F6F6F → #5E5E5E；暗色主按钮用深字（白字在亮蓝上不到 4.5:1）。
