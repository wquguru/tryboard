# 电池供电的温湿度计

## 硬件
- 开发板：Seeed XIAO ESP32C3（ESP32-C3）
- BME280：I2C，SDA = D4 (GPIO6)，SCL = D5 (GPIO7)，地址 0x76
- SSD1306 OLED：同一 I2C 总线，地址 0x3c
- 锂电池供电

## 要求
- 每 [N] 分钟唤醒一次，读温湿度气压，刷新屏幕，然后深睡
- 串口打印一行读数，格式：[格式]
- 框架：ESP-IDF v5.x 或 Arduino-ESP32

## 验收（试板按零件自动生成的检查点）
编译出 flash.bin，拖进 试板 实验台（[地址]），自动跑：
1. I2C 0x76 有回应（BME280）
2. I2C 0x3c 收到帧（OLED）
3. 每次唤醒串口打印一行读数
4. 深睡后能再次唤醒
