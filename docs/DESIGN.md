## 1. 定位与用户故事
用户心里的五个问题，页面按这个顺序走：
1. 我想做个什么？→ **作品首页**：挑作品（气象站、会转身的小黄、透镜小人），或"我有自己的想法"（选型），或"已有固件 → 空白实验台"。
2. 要买什么、难不难？→ **① 采购**：模版带出必选，规则当场说后果，参考价，外壳生成。
3. 固件怎么来、写对了吗？→ **② 实验台**：买的东西已经摆好接好；检查点（原关卡）任务书交给 AI；拖入 .bin 逐条验收。
4. 能做成真东西吗？→ **③ 组装**：验收全过才解锁；装法影响读数。
5. 拿在手里什么样？→ **④ 成品**：能转的 3D 成品，灯、屏、舵机、蜂鸣器都来自同一份固件。

网站是确定性的实验平台，**没有 AI 生成功能**。

## 2. 视觉（A 版：白底极简工程软件）
- 颜色（CSS 变量名建议）：
  - `--bg #FFFFFF`；台面背景 `radial-gradient(120% 90% at 50% 40%, #FFFFFF, #ECEFF3)`
  - `--fg #1E1E1E`，`--muted #6F6F6F`（2026-10-17 由 #8C8C8C 加深，白底对比 3.4 → 5.0），`--line #E6E6E6`，`--line-soft #F0F0F0`，`--field #F7F7F7`
  - `--accent #0D99FF`（选中、主按钮），`--accent-bg #E5F4FF`
  - `--ok #14AE5C`，`--warn #B7791F`（文字）/ `#E8A317`（点），`--bad #F24822`（也是测量标注红），`--bad-bg #FEF2F2`
  - 对比度（2026-10-17）：正文和小字至少 WCAG AA 4.5:1。浅色底上的状态文字用深一档的 ink：`--accent-ink #0A6FBD`、`--ok-ink #0E7A41`、`--warn-ink #8A5A12`、`--bad-ink #C4361A`；白字蓝底（主按钮、首选徽章、勾选框）用 `--accent-strong #0B76C8`。原色只用于边框、圆点、图形和大字。暗色模式原色已达标，ink 等于原色。
- 字体：Noto Sans SC（正文 13px，面板标题 11px/500 灰）、JetBrains Mono（数值、引脚、指纹、时间）。不用 Inter / Roboto / Arial，不用 emoji。
- 面板：浮动，白 95% 不透明，`border 1px var(--line)`，圆角 12，阴影 `0 2px 10px #0000000F`，离屏幕边 12px。
- 状态靠文字 + 颜色同时表达（✓ / ✗ / !），不只靠颜色。
- 暗色模式：P1 做，按同一套变量反转（不是第一批必需）。

## 3. 工作台外壳（四个步骤共用）
```
┌ 左浮动：构建树（顶部：作品名 + 四步切换 采购/实验台/组装/成品） ┐  ┌ 正上：⌘K 命令框 ┐  ┌ 右上：结论 + 下一步按钮 + 视图方块 ┐
│                                                               中间：3D 台面（点零件 / 针脚）                                    │
└ 左栏底：串口 ┘                                                                                         ┌ 右浮动：属性面板（随选中变）┐
                                   底部浮动：分组工具条（选择 转视角 | 放置 连线 | 万用表 尺子 示波器 | 热源 按键）+ 蓝色"再跑一次"
└──────────────────────────────── 最底：时间线（可回退：点一步回到当时的台面和验收结果）────────────────────────────────┘
```
- 构建树：零件 / 连线 / 供电 / 环境 / 固件 / 检查点。选中项高亮 `--accent-bg`。
- 属性面板：分节（11px 灰色标题），行是 `--field` 底的键值对，数值用等宽字体，异常值 `--bad`。
- 点台面上的零件弹**快捷卡片**（BME280：温度滑块、热源、量到芯片；供电线：USB / 外接 5 V）。
- 时间线：放零件、连线、改供电、每次运行都是一步；回退靠确定性重算，不存快照。运行步骤显示 ✓ / ✗。
- ⌘K：搜零件、搜引脚、执行命令（量 3V3、设室温、换外接 5 V 并重跑、回到第 n 次运行）。
- 下一步按钮在条件满足前置灰（实验台全过 → 组装；装完 → 成品）。
- 手机宽度：只读（看作品、成品、清单），面板堆叠；编辑在电脑上。

## 4. 真实器材台面（3D）
- 程序生成，按真实尺寸：面包板 830 孔（2.54 mm 孔距、红蓝电源轨、中间凹槽）；排针（黑塑料 + 金针尖）；开发板 PCB 黑色、每根针旁丝印引脚号、WROOM 金属屏蔽罩刻型号、天线走线、USB-C、BOOT / RST 键、板载 RGB 灯；模块 PCB（OLED 蓝、BME280 紫）带安装孔、丝印、4 针排针；SG90 带固定耳、舵盘、棕红橙三色线。
- 杜邦线：管状曲线 + 黑色插头，颜色惯例：红电源、黑地、黄 SCL、绿 SDA、橙信号。
- 能点到针脚：蓝圈标出 + 标签 + 对应线变粗；属性面板显示角色、实时值和"示波器"小窗。
- 发光：RGB 灯 bloom 照亮周围；OLED / 圆屏帧缓冲作纹理。
- 3D 视图角落写"外观示意，非乐鑫官方模型"；不画乐鑫 logo；型号文字可以画（见 LICENSING.md）。

## 5. 各页面要点
- **作品首页**（2026-10-17 改版，人从三版里选了左右分屏）：只有三段。① 首屏左边主张（"试板：完全免费的线上 AI 智能硬件实验台"，副标题"高仿真 3D 动画，可直接运行真实固件"，按钮"选一个作品""运行我的固件"；2026-10-18 改，见 DESIGN_V2 §7），右边竖向四步流程（采购 / 实验台 / 组装 / 成品，每步一句）。② 作品两列横卡：左边示意图（左上角小标签"运行固件"），右边名字、芯片、参考价（标"估算"）、"开始做"；跑起来后底部出串口最后一行；区块标题旁链到选板。③ 页脚一行：品牌、第三方授权、商标声明。不放简介、要买清单、检查点数、命令行介绍等说明文字。
- **① 采购**：台面平铺零件（未选为虚线）；左树按必选 / 建议 / 外壳分组（必选不能取消）；右栏零件详情（参考价、核价日期、模拟程度）+ 规则检查（可一键补零件）；工具条切模版、换开发板；时间线是清单变更。
- **② 实验台**：见 §3、§4；检查点任务书和"把 .bin 拖到这里"在构建树"检查点"节点的属性面板里。
- **③ 组装**：外壳剖视，未装零件悬在上方；下一件的槽位发亮；BME280 放哪弹卡片；右栏"装法会改变什么"（估算）；时间线到"开机复测"。P1-07 起是 three.js 3D（外壳来自参数化外壳，拖近槽位吸附，工具条：炸开 / 剖面 / 尺子 / 复位视角），没有 WebGL2 时用 SVG 等轴测兜底；右栏末尾是外壳尺寸与警告，链到采购页外壳详情（改高度、导出 STL / 3MF）。
- **④ 成品**：三作品切换；拖动旋转、点按键、热源、滚轮缩放；声音开关；事件时间线；右栏串口 + 真机到手三件事。

## 6. 文案
- 短句、具体、说后果（"只靠 USB 时舵机一转板子可能复位"），不用口号式短句。
- 数值标可信度，只用四档：**仿真验证 / 行为模拟 / 估算 / 必须上真机**；规则类可写"数据手册"或"经验规则"。"估算"紧跟数值，一句只标一次。
- 不把内部信息给用户看：任务号（P1-05）、规则 / 检查编号（R27、W2）、仓库路径（docs/、tools/）、库名（Manifold、three.js）、实现词（tick、墙钟、输入日志、读回、帧缓冲、射线、在线生效）、英文代号（lens、lamp-1）。要说的只有"结果 + 可信度"。检查点任务书会原样复制给 AI，引用别的检查点写中文名，不写编号。
- 句子里不用 `=` `→` `+` `/` 当连词，写"就是 / 后 / 和 / 或"；规格并列（`3V3 / 5V`、型号）可以用斜杠。一句最多一层括号。
- 未做的功能写"暂未开放"。中文里用全角标点，引号用「」。
