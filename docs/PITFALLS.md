# 真机常见坑覆盖清单（D-08）

目标：硬件玩家第一次上真机最常踩的坑，逐条说明 TryBoard 能不能让人提前踩到。三档：
- **能复现**：模拟器里跑同一份固件会出同样的现象（附验收用例 / webtest）。
- **只能提示**：模拟器不出现象，但选型 / 接线检查 / 结果卡会提前警告（附规则编号），结论标「估算」或「需真机确认」。
- **覆盖不了**：既不出现象也不提示，只在「上真机检查清单」（D-06）里提醒去测。

条目来源：乐鑫论坛、ESP-IDF 文档的 FAQ / 注意事项、常见入门教程的排错节。数字只写有出处的。

## 接线与上电
| 坑 | 档 | 依据 / 用例 |
|---|---|---|
| BOOT 脚（C3 GPIO9 / S3 GPIO0）上电被拉低，进下载模式不跑程序 | 只能提示 | 规则 R05、R28（XIAO 隐藏 strapping 脚） |
| C3 GPIO8 / GPIO2、S3 GPIO45 / 46 strapping 电平不对 | 只能提示 | R06、R07、R08 |
| 用了接 flash / PSRAM 的脚（C3 GPIO12–17、S3 GPIO26–37） | 只能提示 | R01–R03（阻止接线） |
| 5 V 信号直接进 GPIO | 只能提示 | R17、接线规则 W2 |
| LED 不串电阻 | 只能提示 | W3 |
| 忘了共地 | 只能提示 | W4 |
| 两个输出接在一起 | 只能提示 | W1、W7（电源短路由 elec 求解） |
| USB 供电带舵机 / 灯带，峰值超 500 mA 掉电重启 | 能复现 | 用例 s3-brownout-usb（USB 供电带舵机 → BROWNOUT_RST 重启）、webtest elec.mjs；R20、R21 |
| 5 V WS2812 用 3.3 V 数据线驱动不稳定 | 只能提示 | R18（需真机确认：多数灯珠其实能亮） |
| 板载 RGB 灯脚位因板子版本不同（DevKitC-1 v1.0 GPIO48 / v1.1 GPIO38） | 只能提示 | R23 |

## 总线与外设
| 坑 | 档 | 依据 / 用例 |
|---|---|---|
| I2C 地址写错（0x3C / 0x3D、0x76 / 0x77） | 能复现 | 用例 s3-ft6236-absent（地址上没有器件 → 固件报「FT6236 no ACK at 0x38」，写错地址同理）；关卡检查按地址统计应答（custom.mjs：没应答判失败）；线太长导致 NACK 见 weather-i2c-nack；W5 / R15 地址冲突 |
| I2C 线太长 / 上拉太弱，高速下读错 | 只能提示 | W6、R16，`--i2c-wire`（P2-11，估算） |
| ADC2 在开 Wi-Fi 后读超时（S3） | 能复现 | 用例 s3-adc2-wifi；规则 R12 |
| C3 用 ADC2（GPIO5）读模拟量 | 只能提示 | R11（IDF 5 已不支持 C3 ADC2） |
| ADC 读数抖、两头不准，不校准偏几个百分点 | 能复现 | 用例 c3-adc-cali、s3-adc-cali（未校准与校准读数对照）；具体芯片偏差标「估算」 |
| 外设数量超过片上资源（RMT / LEDC / I2C 通道） | 只能提示 | R14；驱动初始化报错理应原样出现，但没有验收用例，暂不算能复现 |
| 单线传感器（DHT11 等）靠忙等计时，真机缓存 / 中断让脉宽量偏 | 只能提示 | D-03 时序敏感识别，结果卡标「需真机确认」；逻辑正确性能复现（用例 c3-dht11） |
| WS2812 / RMT 时序 | 能复现 | RMT 模型逐位解码，用例 rgb、strip、lamp-strip |

## 网络
| 坑 | 档 | 依据 / 用例 |
|---|---|---|
| 路由器重启 / 断线后不重连，程序卡死 | 能复现 | 用例 wifi-resilient-reboot、webtest netfault.mjs |
| DNS 失败没处理 | 能复现 | 用例 wifi-resilient-dns |
| HTTP 请求没设超时，服务器不回应时一直等 | 能复现 | 用例 wifi-resilient-silent |
| 信号弱、丢包导致偶发失败 | 能复现（行为模拟） | 用例 wifi-resilient-weak、wifi-resilient-offline；真实 RSSI 与距离覆盖不了 |
| 天线旁边有金属 / 电池，信号差 | 只能提示 | R26、`--antenna-loss`（估算） |
| 只能连 2.4 GHz，家里路由器 5 GHz 合一 | 覆盖不了 | 检查清单提醒 |
| 公网 HTTPS 证书、时间（NTP）没同步 | 覆盖不了 | 真实网络开关只放行 HTTP（C-03） |

## 运行时
| 坑 | 档 | 依据 / 用例 |
|---|---|---|
| 栈溢出 / 空指针，崩溃重启循环 | 只能提示 | 指令级执行理应原样 panic、`--trace` 可查，但没有验收用例，暂不算能复现（待补崩溃固件） |
| 看门狗：任务里死循环不让出 CPU | 能复现 | 用例 c3-wdt、s3-wdt：死循环 5 s 后串口打出「Task watchdog got triggered」并列出 IDLE 与占着 CPU 的任务（TIMG 主看门狗 MWDT 建模）；任务时间线（C-04）能看到谁占满 CPU |
| 双核任务抢同一外设 / 共享变量 | 能复现（行为模拟） | 用例 s3-dual、s3-dual-tasks；真机的缓存与总线争用时序覆盖不了 |
| 需要 PSRAM 但板子没有 | 只能提示 | R30；用例 s3-psram 只验了有 PSRAM 的正常路径 |
| 电池能用几天 | 只能提示 | 功耗估算 ±30%（估算），检查清单提醒实测 |
| 真机 CPU 比模拟器慢 / 快（缓存未命中、flash 等待） | 覆盖不了 | 模拟器一条指令 1 周期，见 DECISIONS D 批 |
| 个体差异：传感器、ADC、晶振每颗不同 | 覆盖不了 | 检查清单提醒标定 |
