# 产品

## 一句话
**买板之前先试板**：在浏览器里运行真实的 ESP32 固件、把想做的项目在 3D 工作台上跑一遍，从而知道该买什么、能不能做成、哪些风险只能上真机。

## 定位（2026-10-16 更新）
**确定性实验台**，面向会用 AI 写代码（vibe coding）的人：AI 写固件 → 在网页实验桌上跑 → 每次结果一样、能验收。网站本身**不带 AI 功能**，只给"交给 AI 的任务书"和验收条件，让用户拿去给自己的 AI。

**在这里改代码（2026-10-21 扩展，F-07b）**：只限 MicroPython 的 `main.py`。用户自己从 micropython.org 下载官方固件（C3 用 `ESP32_GENERIC_C3`，S3 只支持 `SPIRAM_OCT` 变体）上传到实验台，底部面板出现 main.py 编辑器，「运行」经虚拟串口 raw-paste 写入并软复位；输入照常进输入日志，命令行 `--inputs` 重放结果一致。网站不托管 MicroPython 二进制（分发方式 (iii)，DECISIONS 2026-10-21）。C / Arduino 固件仍是「本地编译后上传」，网页不编译。

网站四块（2026-10-18 起首页主张为「试板：完全免费的线上 AI 智能硬件实验台」，地址不带 .html，见 DESIGN_V2 §7）：
- **首页**（`web/home.html`）：首屏就是一块跑着真实固件（weather，ESP32-S3）的实验桌；拖拽装配成成品；成品示意（小黄、透镜小人、温湿度检测器，标"示意"）；7 关路线；示例；命令行验收。
- **实验台**（`web/index.html`）：3D 面包板 + 串口 + 元件编辑器；带 `assembly` 的示例多一个"装配 · 成品"视图。
- **关卡**（`web/levels.html`）：7 关，每关有目标、通过条件、新增零件、任务书、验收命令；上传自己的 .bin 在浏览器里验收，结论和运行指纹与命令行 `tools/check.py` 一致。通过分两档（2026-10-19 起，U-22）：内置参考固件跑通记「◐ 参考跑通」，也能解锁组装 / 成品，让没有工具链的新人先走完全程；自己上传的固件通过记「✓ 我的固件」，是荣誉标记。两档都存在本机浏览器，运行编号与命令行一致。每个检查点的参考固件可下载 flash.bin（直接烧真板）和源码 zip（ESP-IDF 工程）。不锁关、无积分。
- **选板**（原选型助手，`web/select.html`，地址 `/select`）。

装配有三套模板（`web/src/views/templates.ts`）：桌面气象站（weather）、会转身的小黄（spin，舵机转台 + 圆屏脸）、透镜小人（lens，圆屏 + 凸透镜罩）。每套都有一个"装法选择"会影响成品：传感器放哪（进模拟器：读数偏高）、舵盘有没有先回中位（成品偏一个齿 14.4°）、透镜卡高档还是低档（放大 1.35× / 1.08×）。第 07 关"毕业作品"可选 spin 或 lens，各有一套命令行 / 网页一致的验收（`--level 07-spin`、`07-lens`）。任务书经过"只看任务书写固件"的试做（docs/BRIEF_TRIALS.md）修订过。

装配检查（尺寸、线长、温漂）是**估算**，页面上标明；但"传感器贴着芯片"会真实改变模拟器里传感器读到的温度（+2.5 ℃，估算值），成品读数和第 6 关验收都会跟着变。

## 用户
- 看了"ESP32 神器"类视频想入坑、不知道买哪块板的人（esp32-zukai 两篇文章的读者）
- 学生 / 老师：没有硬件也能上实验课
- 已经有板子的人：先在模拟器里验证外设接法和代码，少烧几次板

## 可信度标签（每个结论都要标）
| 标签 | 含义 |
|---|---|
| 仿真验证 | 真实固件在指令级模拟器上跑通，外设模型有验收 |
| 行为模拟 | 外设 / 外部世界是行为级的（虚拟手机、虚拟 Wi-Fi 网络） |
| 估算 | 功耗、性能等按数据手册与标定模型估算 |
| 必须上真机 | 射频距离、天线、模拟噪声、严格时序等 |

## 场景语料库（"大部分玩法"的量化定义）
覆盖率 = 语料库里能启动并出现预期行为的项目比例。按里程碑逐步加入。

| 场景 | 代表项目 | 需要的能力 | 里程碑 |
|---|---|---|---|
| 入门：点灯 / 按键 / 串口 | IDF blink、button、Arduino 示例 | GPIO、UART | M0–M1 |
| 呼吸灯 / 舵机 | LEDC 示例 | LEDC | M2 |
| 彩色灯带 | WLED、led_strip | RMT | M2 |
| 屏幕 / 传感器 | SSD1306、BME280、DHT22 | I2C、单总线（RMT / GPIO 时序） | M2–M3 |
| 智能家居 | ESPHome、Tasmota | Wi-Fi、MQTT、NVS | M6 |
| USB 键盘 / 网卡（执言那类） | TinyUSB HID / NCM | S3 USB OTG | M4–M5 |
| 蓝牙遥控 / BLE 传感器 | NimBLE 示例 | BLE（VHCI） | M7 |
| AI 语音助手 | xiaozhi-esp32 | I2S、Wi-Fi、屏幕 | M8 |
| 摄像头 | XIAO Sense 例程 | DVP 摄像头、PSRAM | M8 |
| 广播假热点（教学） | beacon 示例 | Wi-Fi 原始帧 | M6（只在虚拟环境内） |
